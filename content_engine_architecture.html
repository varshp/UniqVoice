UniqVoice — architecture

A sequential multi-agent pipeline on Google ADK, wrapped in a FastAPI web app. Onboarding runs once to learn the user's voice; the pipeline runs per article. Each agent writes one key to shared session.state; the final agent only reads, to compile the run report.

Colour key — and the course concept each part proves

  • Web app — FastAPI wrapper + browser UI; live-streams the pipeline
  • Agents — multi-agent system (ADK): 6 pipeline agents + 1 onboarding agent
  • Governance — security: semantic guard + fetch cap + output PII strip
  • Tools — MCP servers (search, fetch)
  • Human-in-the-loop — two approval gates (pick the angle · approve the final)
  • Run report — per-run accountability: the take, governance trail, voice match, cost/time ROI

Run the web app: uv run uvicorn server:app --reload --port 8001. Evaluated by an ADK-native suite (pytest + InMemoryRunner), 6 cases passing. Architected for agents-cli deploy to Agent Engine; not deployed for judging.
